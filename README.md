# Beyond the Label Portfolio Site

Static portfolio website for Ally Choi's WRIT 105M project, "Challenging Misconceptions About Autism in Media."

## Pages

- `index.html` - Home page and topic overview
- `about.html` - Creator bio and course context
- `portfolio.html` - Three-project portfolio overview
- `project-beyond-the-label.html` - Project 1 detail page
- `project-misconceptions-uncovered.html` - Project 2 detail page
- `project-field-guide.html` - Project 3 detail page

## Local preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization checklist

- Replace visual placeholders with final project images.
- Add the final Telar embed URL on the Project 2 page.
- Replace carousel placeholders with the final Instagram slide images.
- Add descriptive alt text for every final image.
- Update software/tool labels once the final tools are confirmed.
